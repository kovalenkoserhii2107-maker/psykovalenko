# psykovalenko

Лендинг психологині Тетяни Коваленко. Next.js (App Router), без бази даних.

## Локально

```bash
npm install
npm run dev          # http://localhost:3000
```

## Що де лежить

| Шлях | Що це |
| --- | --- |
| `app/page.tsx` | вся сторінка: шапка, герой, про мене, формати, досвід, соцмережі, питання, запис |
| `app/landing.css` | компонентні стилі лендинга |
| `app/globals.css` | палітра, типографіка, ритм |
| `app/landing-interactions.tsx` | шапка при скролі, мобільне меню, акордеони, поява блоків |
| `app/layout.tsx` | шрифти й метадані |
| `app/manifest.ts` | PWA-манифест |
| `public/assets/img/` | знімки сторінки |
| `index.html`, `assets/` | стара статична копія для GitHub Pages, у збірку не потрапляє |
| `docs/DEPLOY.md` | як випускати |
| `docs/BAZA-ZNESENA.md` | як знести базу на Fly і не платити за неї |
| `docs/MIDJOURNEY.md` | як готувати знімки |
