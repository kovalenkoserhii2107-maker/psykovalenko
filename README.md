# psykovalenko

Лендинг психологині Тетяни Коваленко. Next.js (App Router), статичний
експорт, без бази даних і без сервера.

**https://kovalenkoserhii2107-maker.github.io/psykovalenko/**

## Локально

```bash
npm install
npm run dev          # http://localhost:3000
```

## Що де лежить

| Шлях | Що це |
| --- | --- |
| `app/page.tsx` | вся сторінка: шапка, герой, про мене, формати, досвід, соцмережі, питання, запис |
| `app/landing.css` | компонентні стилі лендинга |
| `app/globals.css` | палітра, типографіка, ритм |
| `app/landing-interactions.tsx` | шапка при скролі, мобільне меню, акордеони, поява блоків |
| `app/layout.tsx` | шрифти й метадані |
| `app/manifest.ts` | PWA-манифест |
| `lib/base-path.ts` | префікс шляхів для GitHub Pages |
| `public/assets/img/` | знімки сторінки |
| `.github/workflows/pages.yml` | збірка й випуск |
| `docs/DEPLOY.md` | як випускати |
| `docs/FLY-ZAKRYTTIA.md` | як закрити Fly і не платити за нього |
| `docs/MIDJOURNEY.md` | як готувати знімки |

## Історія

До вересня 2026 тут були ще кабінет клієнта, CRM психологині, блог з
редактором і анкети-тести — усе на Postgres, з деплоєм на Fly.io. Їх
прибрано: керована база коштувала $24 на місяць проти 12 центів за сам
сайт. Далі й сам Fly став зайвим — статичний лендинг Pages роздає
безкоштовно.

Код нікуди не зник, він у git: кабінет, блог і анкети відновлюються з
коміту `5fa23c8`.
