# Деплой

Сайт — один статичний лендинг на Next.js. Ні бази даних, ні диска, ні
секретів: усе, що потрібне образу, задається в `fly.toml`.

## Разова підготовка

```bash
brew install flyctl        # або: curl -L https://fly.io/install.sh | sh
fly auth login
```

## Звичайний випуск

```bash
git pull
fly deploy
```

`fly deploy` збирає Docker-образ за `Dockerfile` (три стадії: залежності →
збірка → запуск) і піднімає нову машину. Адреса сайту потрапляє в збірку
через `build.args.NEXT_PUBLIC_SITE_URL` — змінні `NEXT_PUBLIC_*`
підставляються на етапі білда, у рантаймі їх уже не змінити. З'явиться
власний домен — замініть значення в `fly.toml` і задеплойте знову.

## Скільки це коштує

Машина налаштована згортатися без відвідувачів:

```toml
auto_stop_machines = "suspend"
min_machines_running = 0
```

Тобто платимо лише за секунди, коли хтось на сайті — це центи на місяць.
Раніше в проєкті була керована Postgres (`fly mpg`), і саме вона давала
майже весь рахунок: база працює круглу добу й не згортається. Тепер її
немає.

## Перевірка перед деплоєм

```bash
npm run lint
npm run build
```

Збірка мовчки вдається — можна деплоїти.

## Корисне

```bash
fly logs                  # живі логи
fly status                # стан машин
fly apps list             # усі застосунки на акаунті (щоб не платити за зайві)
fly open                  # відкрити сайт
```
