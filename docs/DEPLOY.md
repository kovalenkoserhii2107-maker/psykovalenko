# Деплой

Сайт — один статичний лендинг на Next.js. Ні бази даних, ні диска, ні
секретів: усе, що потрібне образу, задається в `fly.toml`.

## Як це працює

Випуск робить GitHub Actions — `.github/workflows/deploy.yml`. Кожен push
у `main` запускає два кроки поспіль:

1. **Збірка і лінт.** Раннер ставить залежності з нуля (`npm ci`) і
   збирає сайт **без файла `.env`**. Це важливо: `next build` підхоплює
   `.env` сам, тож локально помилка «сторінка читає базу на етапі
   збірки» не видно, а на Fly деплой падав. Тепер поламана збірка просто
   не доїжджає до випуску.
2. **Випуск.** `flyctl deploy --local-only`: образ збирається тут-таки на
   раннері й вивантажується в `registry.fly.io`. Без `--local-only` Fly
   підняв би власну машину-складальник, а вона теж рахується в рахунок.

Стан випуску видно у вкладці **Actions** репозиторію. Там же кнопка
**Run workflow** — перевипустити без нового коміту.

## Разова підготовка

Потрібен один секрет репозиторію. Зробити токен:

```bash
fly tokens create deploy -a psykovalenko
```

Далі в репозиторії: **Settings → Secrets and variables → Actions → New
repository secret**, ім'я `FLY_API_TOKEN`, значення — токен. Токен
обмежений одним застосунком: зайвого ним не зробиш.

Токен нікуди більше не вписують — ні в код, ні в `fly.toml`, ні в листи.

## Руками, якщо треба

```bash
brew install flyctl        # або: curl -L https://fly.io/install.sh | sh
fly auth login
git pull
fly deploy
```

## Скільки це коштує

Машина налаштована згортатися без відвідувачів:

```toml
auto_stop_machines = "suspend"
min_machines_running = 0
```

Платимо лише за секунди, коли хтось на сайті — це центи на місяць.

## Домен

Адреса сайту потрапляє в збірку через `build.args.NEXT_PUBLIC_SITE_URL`
у `fly.toml`: змінні `NEXT_PUBLIC_*` підставляються на етапі білда, у
рантаймі їх уже не змінити. З'явиться власний домен — замініть значення
і запуште; Actions випустить самі.

## Корисне

```bash
fly logs                  # живі логи
fly status                # стан машин
fly apps list             # усі застосунки на акаунті (щоб не платити за зайві)
fly open                  # відкрити сайт
```
