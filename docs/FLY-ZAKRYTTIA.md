# Як закрити Fly і перестати отримувати рахунки

Сайт переїхав на GitHub Pages, тож Fly для нього більше не потрібен
зовсім. Порядок такий.

> **Спершу переконайтесь, що сайт живий на Pages.** Відкрийте
> https://kovalenkoserhii2107-maker.github.io/psykovalenko/ — має
> відкритися лендинг зі знімками. Аж тоді закривайте Fly.

## 1. База — це і були ті гроші

Кластер Managed Postgres коштував **$24.13** на місяць проти **$0.12**
за сам застосунок: база працює круглу добу й не згортається, а машина
застосунку згортається без відвідувачів. У панелі кластер показував
оцінку **$39.12** на місяць.

Знесено 30 вересня 2026 через **fly.io/dashboard → Postgres → кластер →
Settings**. Командою те саме:

```bash
fly mpg list
fly mpg destroy <ім'я-кластера>
```

Бэкапи лежать усередині кластера й зникають разом із ним.

## 2. Сам застосунок

Він більше нічого не обслуговує:

```bash
fly apps destroy psykovalenko
```

У браузері: **fly.io/apps/psykovalenko → Settings → Delete app**.

Разом із застосунком ідуть його машина, IP-адреси (`66.241.124.27` і
`2a09:8280:1::18b:5835:0`) і диск `psy_data` — окремо їх зносити не
треба. Хочете прибрати диск раніше:

```bash
fly volumes list -a psykovalenko
fly volumes destroy <id>
```

Адреса `psykovalenko.fly.dev` після цього перестане відкриватися. Якщо
вона десь роздана — в інстаграмі, візитках, підписі — спершу замініть її
на адресу Pages.

## 3. Ключі, які лишились у застосунку

Якщо застосунок зносите — секрети підуть із ним. Якщо вирішили лишити,
приберіть зайве:

```bash
fly secrets list -a psykovalenko
fly secrets unset DATABASE_URL DIRECT_DATABASE_URL AUTH_SECRET AUTH_URL \
  AUTH_GOOGLE_ID AUTH_GOOGLE_SECRET ANTHROPIC_API_KEY \
  ADMIN_EMAIL ADMIN_PASSWORD ADMIN_NAME UPLOAD_DIR -a psykovalenko
```

Прибирайте лише ті імена, що справді є у списку.

**Окремо й обов'язково, незалежно від Fly:** відкличте ключі там, де
вони видані, — Google OAuth у console.cloud.google.com (APIs & Services
→ Credentials) і ключ Anthropic у console.anthropic.com. Видалення
застосунку на Fly їх не відкликає: доки ключ живий, ним можна
користуватися.

## 4. Що на акаунті лишається свідомо

```bash
fly apps list
```

`spacemmo` і `spacemmo-db` — інший проєкт, разом близько **$5.89** на
місяць. Його вирішено лишити. Не зносьте їх заразом.

## 5. Перевірка

```bash
fly mpg list         # порожньо
fly apps list        # тільки spacemmo і spacemmo-db
```

Було **$30.16** на місяць. Лишається **$5.89** за spacemmo — сайт тепер
не коштує нічого. Поточні витрати: **fly.io/dashboard → Billing**.

Рахунок за вересень усе одно прийде: Fly рахує за фактично спожите до
моменту видалення.

## Якщо передумаєте

Кабінет, CRM, блог і анкети лежать у git і відновлюються з коміту
`5fa23c8`. Базу під них можна підняти будь-де: міграції перевірено на
порожній базі — усі п'ять накочуються чисто, а `prisma migrate diff`
після них не бачить різниці зі схемою.
